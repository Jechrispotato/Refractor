📖 Flowchart Symbols Guide

Mermaid syntax → standard flowchart shape mapping:

Mermaid Syntax Shape Meaning
A([Label]) ⬭ Oval / Terminator Start or End of flowchart
B[/Label/] ▱ Parallelogram Input / Output operation
C[Label] ▭ Rectangle Process / Arithmetic / Data manipulation
D{Label?} ◇ Diamond Decision / True-False / Branch
A --> B → Arrow Flowline — direction of logic
A -->|label| B → Labeled Arrow Conditional flowline with text
E((Label)) ○ Circle Page Connector / On-page reference
F[Off Page Connector] ▭ Rectangle (labeled) Off-page continuation (use descriptive label)
subgraph Name … end ⬜ Subgraph Group of related nodes / swimlane
